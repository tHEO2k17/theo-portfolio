# Minimal Portfolio (Static)

This is a minimal, responsive portfolio site generated from your CV.

## Run locally

Open `index.html` directly in your browser, or use a tiny local server:

```bash
cd portfolio
npx serve
```

## Deploy (easy options)

### Netlify (drag & drop)
- Zip the `portfolio/` folder contents (or the folder itself)
- Drag into Netlify Deploy

### GitHub Pages
- Put these files in a repo (e.g. `theo-portfolio`)
- Enable Pages from the `main` branch (root)
